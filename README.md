# 🗃️ Projeto de Banco de Dados Relacional - MySQL

Este repositório contém a construção de um **Banco de Dados relacional** desenvolvido para uma **empresa fictícia**, com foco em estruturação, manipulação e consultas SQL utilizando **MySQL Server**.

## ✅ Objetivos do Projeto

- Criar uma base sólida de dados com **tabelas relacionais**, utilizando chaves primárias e estrangeiras.
- Praticar comandos fundamentais de **manipulação de dados**: `INSERT`, `UPDATE` e `DELETE`.
- Desenvolver consultas SQL utilizando **JOINs** para relacionar diferentes entidades do banco.
- Simular um cenário de uso real com cadastros e operações de negócio.

## 🧱 Funcionalidades Desenvolvidas

- 📌 **Criação de tabelas** com integridade referencial.
- 🔗 **Relacionamentos entre tabelas** via chaves primárias e estrangeiras.
- ✍️ **População da base de dados** com dados fictícios relevantes.
- 🔍 **Consultas SQL com JOINs** para cruzamento de informações.
- ✏️ Operações de **inserção**, **atualização** e **remoção de dados**.

## ⚙️ Tecnologias Utilizadas

- 🐬 **MySQL Server**
- 🛠️ **XAMPP Server** (para ambiente local de testes)
- 📄 **SQL (Structured Query Language)**

## 💻 Como Executar o Projeto

1. Instale o [XAMPP](https://www.apachefriends.org/) e inicie o módulo MySQL.
2. Abra o **phpMyAdmin** ou qualquer outro cliente MySQL.
3. Crie o banco de dados e execute os scripts SQL disponíveis neste repositório:
   - `create_tables.sql`
   - `insert_data.sql`
   - `queries.sql`
